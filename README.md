# MSW-RGX-2627

This repository is the base scaffold for the MSW RGX 2026-2027 project.

## Structure

- `src/` - application source code
- `src/sensors/real/` - hardware drivers
- `src/sensors/dummy/` - mock implementations
- `src/actuators/` - actuator logic
- `src/storage/` - SQLite/data logging helpers
- `src/tools/` - support scripts
- `src/data/` - runtime data output
- `tests/` - automated tests
